# 逆向基本面研究与持续跟踪 Skill

## 1. 适用场景

当用户提出以下请求时使用本 Skill：
- 分析某只股票未来前景；
- 根据成本价判断持仓、加减仓；
- 财报发布后重新评估；
- 查询近期股价并做简短点评；
- 分析某一细分业务的季度吨利润/毛利趋势；
- 询问“下一个关注节点”；
- 要求给出止损线、止盈线；
- 要求持续沿用“太阳纸业式”的分析框架。

核心原则：

> 先找能证伪投资逻辑的证据，再讨论上涨空间；先看企业创造现金的能力，再看利润表的增长；先区分价格走势和基本面，再判断市场是否错杀。

---

## 2. 证据优先级

### P0：公司原始披露
优先使用：
- 年报、半年报、季报；
- 业绩快报、业绩预告；
- 交易所公告；
- 扩产、停产、投资、融资、担保、回购、减持、股权激励公告；
- 投资者关系记录，但管理层表述只视为观点，不等于事实。

重点提取：
- 收入、归母净利润、扣非净利润；
- 营业成本、毛利率、净利率；
- 分产品/分地区收入和毛利率；
- CFO、Capex、FCF；
- 应收、存货、合同负债；
- 现金、短债、长债、净负债；
- 在建工程、固定资产、折旧；
- ROE、ROIC；
- 股本变化和摊薄。

### P1：行业高频数据
优先：行业协会、统计局、海关、交易所、期货交易所、专业产业资讯平台、行业价格数据库。

重点观察：
- 产品现货价；
- 原料价；
- 产品-原料价差；
- 库存；
- 开工率/产能利用率；
- 新增产能/退出产能；
- 进口/出口；
- 下游订单与终端需求。

### P2：海外同行官方披露
至少选2家真正可比的海外同行（若存在），比较：
- 同类业务增长/收缩；
- 利润率；
- Capex；
- 去产能/扩产；
- 产品结构迁移；
- 管理层对行业长期需求的判断。

海外同行用于验证行业结构，不机械套用估值。

### P3：反方证据
主动搜索：
- 供给过剩；
- 需求萎缩；
- 库存积压；
- 技术替代；
- 价格战；
- 大客户流失；
- 项目延期；
- 折旧/财务费用上升；
- 自由现金流恶化；
- 应收/存货异常；
- 海外同行关厂或退出。

### P4：目标公司券商个股研报
默认降权，不能用目标价、评级、一致预期EPS作为核心结论依据。
只能用于发现线索，并回到P0/P1验证。

## 3. 研究流程

### Step 1：定义投资问题
先确认：
- 公司/代码；
- 最新股价；
- 用户成本价（若有）；
- 当前已知持仓逻辑；
- 最新一个财报周期。

若涉及最新股价、财报、公告、行业价格，必须查询最新公开信息。

### Step 2：行业认可度（独立于个股与股价）
在分析公司之前，先对公司所属行业做一个独立的长期判断，避免因为目标公司质地不错而反向美化行业。

默认用约4行完成，至少覆盖以下4个维度：
1. **长期需求**：未来5~10年需求是增长、稳定、周期波动还是结构性萎缩？需求驱动力是否真实且可持续？
2. **供给与竞争**：行业是否容易扩产、价格战是否频繁、集中度是否改善、龙头是否真正拥有议价权？
3. **资本回报**：行业普遍ROIC/ROE、自由现金流、资本开支强度如何？是否存在“利润增长但长期不产生现金”的商业模式缺陷？
4. **结构性风险**：技术替代、监管、人口/地产/宏观依赖、海外替代、客户集中度等是否可能长期压低回报？

必须单独给出：
> **行业认可度：高 / 中高 / 中性 / 中低 / 低（可附1~5星）**

并用一句话说明“为什么”。

行业认可度不得由以下因素反推：
- 目标公司是龙头；
- 当前股价很便宜；
- 最近景气反弹；
- 用户主动挑选了这家公司；
- 公司短期利润增长较快。

如果行业本身长期回报差，即使公司经营优秀，也必须明确写：
> **公司可以优秀，但行业仍不值得高认可。**

如果行业存在结构性衰退、长期供给过剩、资本回报持续低于资本成本、严重价格战或明显技术替代，应敢于给出“中低/低认可度”，而不是默认所有行业都值得长期配置。

### Step 3：拆利润来源
不能只看总收入和总利润。
必须回答：
- 哪个业务在贡献增量利润？
- 哪个业务在拖累？
- 利润增长是量、价、成本、产品结构还是非经常项驱动？

至少输出一句：

> 当前利润增长主要由 ______ 驱动，而不是 ______。

### Step 4：季度环比拆解
财报发布后，优先拆单季度，而不是只看累计同比。

若财报只披露累计数，使用差分法计算：
- Q2单季 = H1累计 - Q1；
- Q3单季 = 前三季度累计 - H1；
- Q4单季 = 全年 - 前三季度。

重点比较：
- 收入 QoQ / YoY；
- 归母净利润 QoQ / YoY；
- 扣非净利润 QoQ / YoY；
- 毛利率 QoQ / YoY；
- 净利率 QoQ / YoY；
- CFO、Capex、FCF季度变化。

特别关注：

> 收入创新高，但利润/毛利率环比下降。

这通常意味着增量收入的边际利润率下降，应标记为黄色或红色信号，而不能只用同比增长掩盖。

### Step 5：细分业务吨利润/价差分析
若公司没有披露单季度吨利润，不得伪造精确值。

使用三层方法：
1. 公司披露的分产品收入、成本、毛利率；
2. 行业产品价格与原料价格；
3. 公司总体利润率/单季利润变化进行交叉验证。

优先判断“趋势”而不是虚假精确：
- 低位稳定；
- 扩张；
- 高位维持；
- 边际收窄；
- 明显恶化。

如果做吨毛利代理估算，必须明确写“代理估算”，不得冒充公司披露值。

对一体化企业，重点看：

> 成品售价 - 综合原料/纤维成本

而不是单看某一种原料涨跌。

### Step 6：行业阶段判断
区分：
- 强复苏；
- 弱复苏；
- 筑底；
- 下行；
- 结构性衰退；
- 供给出清；
- 产能过剩但龙头集中度提升。

至少检查：价格、库存、开工率、产能、需求。

禁止：
- 涨价函 = 实际成交价上涨；
- 价格低位反弹 = 行业反转。

### Step 7：现金流与资本纪律
计算：

> FCF ≈ CFO - Capex

重点观察：
- Capex/CFO；
- 在建工程；
- 净负债；
- 财务费用；
- 折旧；
- ROE/ROIC。

对重资产企业尤其警惕：

> 利润增长 + 高Capex + 持续负FCF。

若企业持续扩产，必须回答：
- 行业是否需要这些新增产能？
- 新产能达到什么利用率才合理？
- 增量利润能否覆盖新增折旧、利息与资本成本？

经典风险链：

> 扩产 → 借钱 → 供给增加 → 产品降价 → 靠规模降成本 → 再扩产。

### Step 8：资产负债表质量
至少关注：
- 带息债务；
- 净负债；
- 资产负债率；
- 流动比率；
- 应收账款增速 vs 收入增速；
- 存货增速 vs 收入增速。

若出现：

> 收入+10%，应收+40%

必须标黄并跟踪信用政策、渠道库存和回款质量。

“应收上升但库存稳定”与“应收和库存同时暴涨”风险等级不同。

### Step 9：价格走势与基本面分离
股价下跌时不要直接推导基本面恶化，也不要因为基本面未坏就忽略价格信号。

必须分成两条判断：

> 价格趋势：强 / 中性 / 弱 / 明显恶化
>
> 基本面：强化 / 未证伪 / 边际恶化 / 已证伪

当出现：
- 股价连续破位；
- 但尚无重大经营利空；
- 且财报即将披露；

优先选择等待财报验证，而不是机械抄底。

### Step 10：价格与财报的预期差
财报公布后观察“价格反应”：

- 前期大跌 + 财报不差 + 股价止跌/反弹：可能是过度悲观修复；
- 前期大跌 + 财报不差 + 仍放量大跌：继续查找市场在交易的新风险；
- 财报差 + 股价不跌：可能坏消息已充分定价；
- 财报好 + 股价不涨：可能估值、行业或Capex压制仍在。

价格反应不能替代基本面，但可以作为“市场预期差”信号。

### Step 11：TTM估值
优先使用已经发生的数据：

> TTM净利润 = 上年全年净利润 - 上年同期累计净利润 + 本年同期累计净利润

然后计算：
- 最新摊薄股本；
- TTM EPS；
- 当前PE；
- 用户成本价对应PE；
- PB；
- 适用时计算FCF Yield / EV/EBITDA。

禁止简单说“10倍PE很便宜”。
必须解释：

> 对该行业、资本强度和ROIC而言，10倍为何便宜、合理或昂贵？

### Step 12：熊市情景
必须建立完整恶化链并量化：

> 需求弱 → 库存升 → 产品降价 → 毛利率降 → 新产能利用率不足 → 折旧上升 → FCF恶化 → 净负债增加 → 估值压缩。

至少给出：
- 保守净利润；
- EPS；
- 低周期合理估值倍数；
- 对应股价。

### Step 13：牛市情景
不得只写“涨价”。
优先使用：
- 利用率爬坡；
- 产品结构升级；
- 单位成本下降；
- 供给退出；
- Capex见顶；
- FCF转正；
- 净负债下降；
- ROIC提升。

核心问题：

> 公司什么时候从投入期进入现金收获期？

## 4. 持仓决策规则

### 4.1 持有
当：
- 价格弱，但基本面未证伪；
- 估值已回落；
- 核心业务利润仍有韧性；
- 财报即将提供关键验证；

可给出“持有、等待验证”，避免因为短期跌幅机械止损。

### 4.2 加仓
只有在以下至少两项同时改善时才提高加仓评级：
- 核心业务毛利率稳定/回升；
- CFO强；
- Capex下降；
- FCF转正；
- 新产能爬坡正常；
- 净负债不再上升；
- 股价明显低于基本面合理区间。

仅因为“跌了10%/20%”不得作为加仓理由。

### 4.3 减仓/止损
优先使用“基本面止损”，例如：
- 核心毛利率连续两个季度明显恶化；
- 行业库存持续上升且价格下跌；
- CFO下降而Capex高企；
- 负债快速上升；
- ROIC持续下降；
- 新项目爬坡失败；
- 原持仓逻辑被财报证伪。

用户明确要求价格止损线时，可提供价格参考线，但必须与基本面触发条件绑定。

### 4.4 止盈线
止盈不是“涨到成本价就卖”。
结合：
- TTM估值；
- 周期位置；
- 历史估值；
- 未来利润质量；
- 用户成本价；
- 上方价格结构。

优先给“开始分批兑现”的价格，而不是一次性清仓点。

## 5. 下一关注节点生成规则

当用户问“下一个关注节点是什么时候”时，不只回答下一份财报日期。

按三层节点输出：

### A. 高频行业节点
未来1~2个月：
- 产品价格；
- 原料价格；
- 库存；
- 开工率；
- 订单。

### B. 经营节点
例如：
- 新产能投产后3~6个月；
- 年底Capex执行进度；
- 项目达产/试产时间；
- 旺季/淡季验证。

### C. 财务节点
- 业绩快报；
- 年报；
- 一季报/半年报/三季报。

必须说明：

> 下一次最关键的验证问题是什么？

例如：
- 新产能是否“增量增利”；
- 毛利率是否守住某水平；
- FCF能否转正；
- Capex是否见顶。

## 6. 红黄绿灯系统

### 红灯
- 核心产品毛利率连续下降；
- 库存上升 + 产品价格下跌；
- 大扩产但利用率下降；
- CFO下降、Capex仍高；
- FCF持续恶化；
- 净负债快速上升；
- ROIC/ROE持续下降；
- 新项目延期或回报不达标；
- 海外同行集中关停同类业务。

### 黄灯
- 涨价函多但成交价不涨；
- 收入增长但毛利率下降；
- 利润增长依赖单一业务；
- 在建工程快速增长；
- 应收明显快于收入增长；
- 管理层乐观但行业数据不支持；
- 新产能开始贡献收入但尚未贡献利润。

### 绿灯
- 产品价差扩大；
- 核心业务毛利率提高；
- 库存下降、利用率提升；
- 新产能顺利爬坡；
- Capex见顶；
- FCF转正并扩大；
- 净负债下降；
- ROIC上升。

## 7. 标准输出模板

### 完整版
1. 结论先行；
2. **行业认可度（约4行，独立于个股与股价）**；
3. Q1/Q2/Q3/Q4单季拆解；
4. 利润来源；
5. 行业真实状态；
6. 核心细分业务吨利润/价差；
7. 公司竞争力；
8. CFO/Capex/FCF；
9. 资产负债表；
10. 海外同行；
11. 熊市情景；
12. 牛市情景；
13. TTM估值与成本价；
14. 下一关注节点；
15. 红黄绿灯；
16. 最终评分与操作倾向。

### 简短股价点评版
用户要求“查询最新股价，做简短点评”时只输出：
- 最新价、当日涨跌；
- 当前价格趋势；
- 基本面是否改变；
- 关键压力/支撑或估值位置；
- 一句话操作倾向。

禁止重新输出整篇基本面报告。

### 止损/止盈简版
用户要求“只给两条线”时只输出：
- 止损参考线：X；
- 止盈参考线：Y；
- 最多补一句触发条件。

不要展开长分析。

## 8. 评分体系

满分10分，可使用：
- 公司经营能力；
- 成本竞争力；
- 产品结构；
- 最新季度业绩质量；
- **行业认可度（长期需求/供给格局/资本回报/结构性风险）**；
- 行业景气；
- 行业长期结构；
- 资产负债表；
- 自由现金流；
- Capex纪律；
- 资本效率；
- 当前估值；
- 用户成本价赔率。

评分必须有数据支撑，不能凭感觉。

## 9. 研究纪律

1. 不因为用户持有而寻找支持持有的理由。
2. 不因为股价下跌就默认便宜。
3. 不因为龙头身份就忽视行业过剩。
4. 不因为利润增长就忽视FCF。
5. 不把涨价函当成交价。
6. 不把扩产等同成长。
7. 不用海外高估值机械套国内公司。
8. 管理层表态是观点，经营数据才是证据。
9. 个股券商目标价和一致预期不作为核心论据。
10. 财报后优先拆单季，而不是只看累计同比。
11. 收入创新高但利润率下降，必须解释边际回报。
12. 股价与基本面要分开判断。
13. 价格大跌但财报未证伪时，不因恐慌机械止损；价格大跌也不自动抄底。
14. 所有精确吨利润若非公司披露，必须标记为估算。
15. 优先寻找能推翻当前投资逻辑的数据。
16. 行业认可度必须先于个股结论形成，不能因为目标公司优秀、股价便宜或用户主动选择该股票而抬高行业评分。
17. 对长期资本回报差、结构性衰退、供给持续过剩或技术替代明显的行业，必须允许直接给出“不看好/低认可度”。

## 11. 太阳纸业案例提炼出的通用方法

这些是方法论，不保存具体价格和财报数值：

- 重资产周期股不能只看净利润，同比漂亮可能掩盖环比边际走弱；
- 财报累计数据应尽量反推出单季数据；
- 细分业务没有季度披露时，用公司分部数据 + 行业价差 + 总体利润率交叉验证，只判断趋势，不伪造精确吨利润；
- 新产能投产初期要观察“收入增长是否伴随利润增长”，以及折旧和利用率；
- 行业差但龙头利润不差，说明成本/产品结构优势存在，但不等于行业风险消失；
- 真正的长期价值重估通常发生在Capex见顶、FCF转正、净负债下降、ROIC回升之后；
- 股价提前下跌可能交易未来风险，财报后的价格反应是重要的预期差信号；
- 对持仓者，最重要的不是精确预测股价，而是持续更新“投资逻辑是否被证伪”。

## 12. 估值路径选择协议（v2.2增补，必须执行）

**本节只补充原框架，不替换第3节Step 11的TTM计算、周期分析、现金流与投资纪律。** 每次涉及估值，必须显式输出：`主路径 / 辅助交叉验证路径 / 不采用其他路径的原因 / 关键假设`。TTM PE是事实描述，不自动成为主估值路径。

1. **稳定、成熟且盈利可持续**：主路径正常化PE或FCF收益率；辅助ROIC、EV/EBITDA与历史周期分位。若资本密集且周期显著，须用中周期盈利而非景气顶峰利润。
2. **高增长且盈利已初步兑现**：主路径逆向盈利估值 + 2~5年情景远期PE；辅助订单/收入/毛利/费用率/现金流与可比公司的经营质量；不以TTM PE单独否决，也不以高成长叙事免除估值纪律。
3. **周期谷底、净利润接近零、负PE或一次性损益扭曲**：先拆周期低谷、非经常损益、研发与扩张投入、结构性衰退；主路径按可验证经营形态选正常化EBIT/PE、EV/EBITDA、EV/Sales或PB资产法，必要时DCF/清算价值；辅助资产质量和现金流核验。不能因PB低推导低估，也不能用不可盈利公司的负PE作倍数比较。
4. **跨行业、多业务、参股/控股题材公司**：主路径SOTP（分部估值）；辅助权益穿透后利润、经营现金流、潜在摊薄及母公司市值反推。必须分别估值成熟主营与创新业务，不允许把新业务行业估值套在集团全部收入/利润上。
5. **净现金、债务、少数股东权益、股权稀释显著**：用企业价值到归母股权价值的桥接，校准EV与市值，防止双重计算；母公司归属收益与子公司整体利润不得混用。

### 12.1 PE四层核验
- **TTM PE**：市值/滚动归母净利润，披露取数日与股本口径，说明非经常项、周期位置；若分母极小或为负，标为失真。
- **正常化PE**：按周期中枢产销价差、正常产能利用率、税费和折旧计算归母净利润；列明为何不是简单平均历史利润。
- **远期PE**：至少给出保守/中性/乐观三条未来盈利路径，说明2~5年收入、净利率、利润与可能合理倍数，扣除稀释风险。
- **逆向PE**：从现价市值推回目标年份所需净利润与盈利CAGR，再对照可服务市场、份额、单价、产能、订单、成本、竞争和资本开支。若无可靠预测，明确说“无法可靠定价”，而非编造远期PE。

### 12.2 估值兑现公式（必须检查双变量）
在股本稳定且归母EPS与净利润同步增长的简化前提下：

`预期股价倍数 ≈ (期末归母净利润 / 基期归母净利润) × (期末合理PE / 当前PE)`

注意市场对PE的压缩可能超过盈利增长：**高增长≠高收益**。输出“盈利兑现风险、终值PE压缩风险、融资摊薄风险”。利润基数异常小则禁用该简式，改用绝对利润、EV或SOTP估值。

**逆向目标检验**：`目标年归母净利润 = 当前市值 / 假设目标年PE`；`要求CAGR = (目标年利润 / 合理基期利润)^(1/年数)-1`。对基期利润为负、接近零或异常项驱动时不得机械算CAGR。当前市值与目标年终值均需注明是否考虑净现金/股本变化。

### 12.3 防止两类PE陷阱
- **低PE陷阱**：利润处于景气高点、现金回收弱、ROIC低于资本成本、维持性Capex大、行业长期萎缩、盈利由资产处置/补贴/公允价值驱动；必须先做利润回落情景再评价“便宜”。
- **高PE陷阱**：利润起点极低形成虚高倍数、成长已充分透支、市场空间与份额假设不现实、研发资本化或应收推高利润、终局竞争趋于同质化；必须计算即便业绩兑现但PE压缩时的收益。
- **例外原则**：高PE可以合理但必须证据支持；低PE可以便宜但必须排除盈利不可持续。禁止以近期股价结果倒推当初估值必然正确。

## 13. “市场到底在为什么付钱”定价归因模块

将研究结论拆成三张不互相替代的判断：

1. **企业内在经营价值**：可持续归母利润、自由现金流、ROIC-WACC差值、资产质量和资产负债表。
2. **市场隐含预期**：当前市值要求的未来利润、增长持续期、市场份额、利润率、终值倍数；记录哪些预期已被订单/交付/现金流验证，哪些仍属传闻/题材。
3. **股价交易驱动**：行业景气、流动性/风格偏好、政策与事件催化、指数资金、短期风险偏好；只把量价、涨跌停、资金流作弱证据，不把其当成基本面因果证明。

输出四句：`经营事实 / 市场定价假设 / 已证实与未证实 / 最关键证伪节点`。

### 13.1 题材与主业错位穿透
看到名称相似或同属申万行业，但股价严重分化时：
- 先列主营收入、毛利、归母利润与现金流贡献，再列新业务的**独立财务体量**；
- 穿透控股/参股关系：持股比例、少数股东损益、资产负债、潜在增资、关联交易、母公司实际可分享现金；控制权不等于100%经济收益；
- 区分`概念关联→研发/送样→客户认证→订单→收入→毛利→归母净利润→现金流`八层证据；不得由“有某业务”直接跳到“享有该业务全部高估值”；
- 分部估值中明确业务交叉与集团费用，禁止重复估值；研发阶段业务可采取概率加权情景，必要时给零价值保守情景；
- 对比公司时若经营驱动不同，先停止机械同行PE比较，重新确定真实价值驱动。

### 13.2 同行业反向走势专题
遇到“青山纸业强涨、太阳纸业走弱”或类似情形时，默认做**同业表象剥离**：
- 同行业分类是否等于相同利润池？业务构成、下游、区域和产品周期是否可比？
- 一方是否有非主营概念、资产重估、股权故事，另一方主要靠主营现金流？
- 对**核心主营**分别计算盈利质量/现金流/ROIC，对**题材部分**单独算权益穿透价值。
- **强制双结论**：`哪家公司经营质量更高` 与 `哪家公司当前价格更有安全边际` 分开写。不得由前者自动推出后者，也不得由短期强弱推断长期价值。
- 若出现高估值/涨停，列出需要兑现的年归母利润、对应新增业务利润和实现条件；若低估值/滞涨，列出悲观情景、持平情景与价值陷阱证据。
- 不可把“某题材导致上涨”写成已证实因果：公告、新闻、交易时段与行业板块联动只支持合理归因，并标记证据强弱。

## 14. 产业成长空间、替代与终局竞争

成长股必须同时分析：
- **TAM/SAM/SOM**：终端市场需求、实际可服务市场、公司可获得份额；禁止直接用TAM乘市占率当利润。
- **需求来源**：新增需求、存量替换、国产替代、产品提价分别测算，避免重复计算。
- **供给响应**：竞争对手扩产、良率爬坡、价格下降、技术标准变化及客户自研。
- **技术迭代/替代**：现有方案的单位经济性是否被新路线改善；谁有切换成本、专利/软件/认证壁垒，替代发生的时间窗口；例如光通信要监测硅光、CPO等方案对产业链利润池的迁移，不得预设单一路线必胜。
- **利润传导链**：市场规模→公司份额→订单/交付→收入→毛利→研发销售与折旧→归母利润→现金流，逐层验证。
- **终局ROIC**：高增长阶段后的资本回报能否覆盖资本成本；终值倍数不能永远建立在超高利润增长上。

## 15. 估值与交易结论的独立性；评级与触发条件

完整报告至少独立提供以下四个状态，不得揉成单一分数：

| 维度 | 回答的问题 |
|---|---|
| 行业认可度 | 行业长期资本回报是否值得认可？ |
| 公司质地 | 竞争优势、利润现金含量、ROIC是否优秀？ |
| 估值吸引力 | 在**当前价格**下有无安全边际，反推条件是否苛刻？ |
| 市场预期/催化 | 市场为何给这个价格、近期什么事件可能改变预期？ |

**评分修订**：原10分综合评分保留，但必须附上述四项拆解；不能因为市场热度上升就抬高“公司质地”，不能因为低PE就抬高“估值吸引力”。价格/技术信号可用于执行和风控，不得替代估值。

**情景与概率纪律**：保守/中性/乐观情景需给假设、对应利润、估值路径、价格范围、关键观察节点；概率若无可验证依据，只报情景不伪造概率。对于创新业务采用阶段成功率时须说明是主观假设而非统计事实。

**价格参考线纪律**：止损/止盈线须注明是技术价格线、估值线还是基本面证伪线；风险管理先考虑组合集中度、流动性、预期损失，不因“未来更大”无限加仓。

## 16. 新增反证与跟踪清单

每次复盘额外检查：
- 市场乐观叙事中，**哪一条关键增长假设至今没有兑现？**
- 公司增速超过同行，究竟来自市占率、周期反弹、基数效应还是资本化/并购？
- 过去12个月上涨中，EPS增长贡献多少，PE扩张贡献多少？对同口径股价、EPS的PE变化做近似分解，不可用累计收益直接归因。
- 若未来净利润增长达到预期，但估值回到行业中枢，投资回报如何？
- 若按目前现金流不变，不依赖概念业务，当前估值是否仍能支撑？
- 反面证据：关键客户验证失败、订单转化低于预期、收入不产生经营现金、应收和存货异常、行业降价及融资摊薄。
- 保存关键假设的时间戳、数据来源与下次证伪条件，复盘时比较**此前预期和现实的差异**，避免事后归因。

## 17. 案例锚点（仅记录方法，不冻结行情结论）

- **长川科技/金海通**：高TTM PE在利润低基数、快速成长中可能被盈利消化；必须同时模拟成长未兑现和终值PE下降的情况。历史利润高增不等于未来继续高增。
- **青山纸业/太阳纸业**：两家公司名义上同属纸业，但若一方因控股子公司光通信等概念交易、另一方依赖造纸主营，不能直接比较两者整体PE来判价值优劣。应采用SOTP + 权益穿透 + 业务兑现分层，对主营与主题业务分开估值；同时分别回答经营质量和当前安全边际。
- **太阳纸业**：低PE不自动是错杀。须检验纸价、浆价、吨利润、供需产能、维持性Capex、ROIC和未来现金流，排除周期顶部盈利和长期低资本回报。

**一句话总纲**：寻找的不是绝对最低PE，而是“可验证的未来盈利能力”与“市场当前隐含预期”之间的错误定价。

## 18. 仓位管理与交易风险模块（v2.3新增，优先级高于买卖价格线）

### 18.1 适用原则与风险预算

每次输出“建仓、加仓、继续持有、减仓”建议，除基本面估值外，必须独立判断：**研究结论是否正确**与**即使研究错误，组合能否承受**。好公司、好价格不等于值得重仓。

在用户未提供明确风险承受能力、流动性需求、其他持仓和资产相关性前，**不能给出精确的个性化最优仓位**；使用以下保守默认示例，并标注可由风险预算调整，而非普适标准：
- 首笔试探仓：总投资资产的 **5%—10%**；业绩验证不足/高波动成长或题材股：可更低。
- 单只普通股票：通常建议设置 **15%—20%** 的软上限；不因价格下跌自动抬高上限。
- 单一公司接近 **30%** 需明确标记高度集中风险，超过 **50%** 标记极端集中风险；接近100%原则上视为不可接受的单一个股集中度，除非投资者明示具有特殊专业策略及相应保障，仍需提示尾部风险。
- 不鼓励杠杆、融资补仓或以生活应急资金承受个股波动；不把现金持仓视为必须快速使用的额度。
- 已持有的不同股票若暴露于同一行业、同一大客户、同一宏观因素，应按相关风险因子汇总评估集中度，不可只看单票比例。

### 18.2 建仓前强制计算

在给出操作建议时尽量报告以下四项；缺失数据须说明，而非填假值：

1. 当前仓位及计划增仓后的 **组合权重**：`计划持仓市值 ÷ 计划总投资资产`；明确采用市值口径，不用持仓成本计算权重。
2. **价格下跌压力测试**：假设该股票下跌10%/20%/30%/50%，其他资产价格不变，组合机械影响约为 `该股权重 × 跌幅`，并提示相关资产同步下跌时实际损失可能更大。
3. **投资逻辑失效的情景损失**：依据保守利润、终值估值与股本推导合理价，计算 `(当前价 − 保守情景价) / 当前价`；不得将技术止损价当作最坏情况，跳空/流动性会导致实际亏损超过止损预算。
4. **流动性与可承受风险预算**：用户预设的单笔容忍损失、账户最大允许回撤、计划持有期和是否存在短期用钱需求。

风险预算辅助上限：`仓位上限 ≈ 单笔允许组合损失比例 ÷ 假设的个股不利情景跌幅`。例如允许组合损失2%、个股不利情景跌幅30%，仓位上限约6.7%；此式只是压力测试，不是预测概率或止损保证，遇到尾部风险和相关性应更保守。

### 18.3 分批建仓与补仓纪律

任何补仓请求必须**独立重做当前价估值**，并写清：
- 首次建仓时的原始投资论点、当时预期与当前新证据有何变化；
- 是否只是因为成本价下降、希望解套或“不甘心”，而不是新增正面证据；
- 增仓后权重、剩余现金、压力测试是否仍符合预设风险预算；
- 新价格的安全边际是否相对**重新估计的合理价值**扩大，而非仅相对原买入价下降；
- 至少有一项可核实的基本面/预期改善证据，且不得触及明确证伪条件；对高不确定性成长股，优先等待订单、利润、现金流等里程碑验证。

仅“跌了10%”“PE更低”“降低成本”都不构成补仓依据。不得为了让平均持仓成本好看而把小仓滚成满仓。若计划加仓导致超出单票/行业/组合风险预算，**即使估值看起来吸引，也应明确建议暂停加仓或先降低风险暴露**。

### 18.4 三种退出路径及执行限制

事前写清三类不同退出触发器，不得在股价下跌时随意相互替代：

- **基本面证伪退出**：核心产品和市场空间判断失效，盈利/现金流持续低于原情景，竞争格局恶化，或财务风险超阈值。
- **估值到位退出**：市场价格已显著透支可验证的增长与终值估值；给分批减仓区间而非绝对顶部预测。
- **组合风险退出**：权重过高、相关性集中、账户回撤触及预设预算、急需流动性，或实际波动超过持仓者可承受范围。即使基本面暂未证伪，风险退出也可以合理。

技术止损可用于执行，但不能保证按线成交。风险退出不应被简单解释为“投资能力差”；同时也不能把事后继续下跌当成此前卖出决策正确的充分证明。

### 18.5 仓位—回撤—行为偏差联动

对重仓个股额外检查：
- 是否从“长期经营价值判断”逐渐转为“只盼反弹解套”；
- 是否被锚定在首购价、摊薄后成本或历史高点；
- 是否把下跌理解为市场必然错误，忽略经营数据变化；
- 是否因错过其他热门股而突然提高风险偏好或追涨；
- 是否在近期巨幅亏损后采取报复性交易。

这些是可供自我核查的交易偏差，不应据此断言用户心理状态。必要时以降低仓位、暂缓补仓和复核原始研究笔记代替情绪化的“加快回本”。

### 18.6 交易记录与复盘卡（每次建仓/补仓/卖出）

记录下列项目；历史交易不得用事后已知信息伪造当时判断：

| 字段 | 记录要求 |
|---|---|
| 时间与成交 | 日期、成交价、股数、费用，区分收盘价与实际成交价 |
| 组合敞口 | 交易前后单票权重、行业合并权重、现金与杠杆 |
| 投资论点 | 当时可获得的核心数据、估值主路径、隐含盈利要求 |
| 预设失败条件 | 可证伪的基本面事件和估值/回撤条件 |
| 决策性质 | 新建仓、研究驱动补仓、价格驱动补仓、风险减仓、估值退出 |
| 结果归因 | 经营假设偏差、估值偏差、仓位失控、执行偏差、运气与市场波动分别评价 |

**案例：顺网科技（只用于复盘原则，不当作买卖建议）**
- 已知交易叙述：2026-05-21约25元首次买入，初始约50%资金；下跌后补仓，组合中单票权重最高接近100%，摊薄成本约22元；2026-06-01因难以承受持续下跌，借反弹全部清仓。实际分笔数量、成交价、交易费用和最终收益率未核实，不得杜撰。
- 可明确识别的首要问题：**单一成长股仓位过大，价格下行时继续提高组合集中度，使投资判断的不确定性被放大为账户级风险**。
- 不能在证据不足时下结论：买入研究一定错误、每次补仓必然错误、最终清仓一定正确；需用对应交易日已经披露的经营信息验证。
- 可执行教训：首次买入前先设置单票与总回撤预算；补仓前重估合理价值和不利情景；仓位越大越要优先执行组合风险退出，而不是靠摊低成本维持信心。

### 18.7 标准输出增补与优先级

凡用户问“能否建仓/加仓/继续持有”，在原标准报告的估值结论后，增加一个简短 **「组合风控」** 段落：当前权重（已知时）、建议首次/最高权重（根据用户风险预算）、下跌20%/30%的组合冲击、何时允许补仓、何时必须减仓。若不知总投资资产或现有仓位，只提供条件式方案，不伪称已经计算准确组合风险。

优先级：**本金流动性与杠杆约束 > 组合集中度和回撤预算 > 基本面证伪 > 当前估值吸引力 > 技术进出场**。这一顺序不替代原有研究流程，而是为执行提供硬性约束。
